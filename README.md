# D. Anushka — AI & ML Developer Portfolio

A futuristic, high-performance developer portfolio built with React, Vite, Three.js, GSAP, and custom cyber/neon aesthetic design systems.

---

## ✨ Features & Highlights

- **3D Physics Interactive Lanyard ID Card**: Powered by `@react-three/fiber`, `@react-three/drei`, and `@react-three/rapier`. Realistic card physics, dynamic spring joints, and interactive drag reveal texture swap (ID No. `24ME1A4277`).
- **Interactive Particle Text**: Interactive canvas particle simulation with hover scatter, idle drift, and fluid physics.
- **Ambient Electric Lightning**: WebGL procedural shader lightning effects.
- **Magic Bento Component**: Cosmic star particles, cursor-following global spotlight, dynamic border glow, 3D card perspective tilt, and ripple shockwaves.
- **Staggered Menu Navigation**: GSAP-driven full-screen navigation with multi-layer color sweep underlays, slot-machine animated "Menu" ⇄ "Close" toggle, and cascading numbered items.
- **Smooth Scrolling**: Universal offset-calculated smooth scrolling for all in-page navigation anchors.
- **Dark / Light Cyber Aesthetics**: Sleek dark mode default with responsive glassmorphic cards and glowing neon accents.

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 6
- **3D & Canvas**: Three.js, React Three Fiber, React Three Rapier, MeshLine
- **Animations**: GSAP (GreenSock Animation Platform)
- **Icons**: Lucide React
- **Styling**: Vanilla CSS Design Tokens, Glassmorphism, CSS Modules & Animations

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/anuanshu964/D-Anushka-Portfolio.git

# Navigate into the project folder
cd D-Anushka-Portfolio

# Install dependencies
npm install --legacy-peer-deps

# Start local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
